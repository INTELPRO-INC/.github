## INTELPRO 英特博

AIoT chip design from Zhubei, Taiwan. We build RISC-V SoCs with Bluetooth LE Audio,
Wi-Fi 6 and on-device NPU AI, and deliver them as turnkey solutions: chip, SDK and
reference boards.

### IPRO SDK

One SDK for the IPRO7 and IPRO6 families: FreeRTOS and Zephyr, BLE 5.4 and LE Audio,
Wi-Fi 6, on-device NPU AI and imaging.

| Chip | Highlights |
|---|---|
| **IPRO7AI** | IPRO7 plus an NPU and 8 MB in-package PSRAM, for on-device vision AI |
| **IPRO7** | RISC-V wireless SoC with BLE 5.4 and LE Audio, 802.15.4, ISP and MJPEG |
| **IPRO6S** | RISC-V SoC with built-in Wi-Fi 6, BLE 5.4 and BR/EDR |
